# 🚀 Personal Portfolio Website

A modern, responsive personal portfolio website built with React.js. 
Features a clean dark theme with smooth animations and a fully 
responsive design that works on all devices.

## 🌐 Live Demo
[👉 Click here to view my portfolio](https://aesthetic-tanuki-8244ad.netlify.app/)

## ✨ Features
- 🎨 Modern dark theme with neon green accents
- 📱 Fully responsive design
- ⚡ Built with React.js components
- 🎯 Smooth hover animations
- 📬 Direct contact links

## 🛠️ Tech Stack
| Technology | Usage |
|------------|-------|
| React.js   | Frontend framework |
| CSS3       | Styling and animations |
| JavaScript | Logic and interactivity |
| Git/GitHub | Version control |
| Netlify    | Deployment |

## 📂 Sections
- **Hero** — Introduction and call to action
- **Projects** — Featured projects with live links
- **Skills** — Technical skills grouped by category
- **Contact** — Ways to get in touch

## 🚀 Run Locally
```bash
# Clone the repo
git clone https://github.com/srathnasabapathi964/my-portfolio.git

# Go into the folder
cd my-portfolio

# Install dependencies
npm install

# Start development server
npm start
```
